# Kanso 0.10.9 · What's new

## 1 · Typed dates in tasks

- Description: Type "tomorrow 3pm" in a task and it becomes the due date.
- Shows: A task line gets "tomorrow 3pm" typed in. A hint appears, Tab is pressed, and the due date and time fill in.
- Covers: b76080f

## 2 · New canvas in Canvases

- Description: The New button in a Canvases list now makes a canvas.
- Shows: In a Canvases list, New is clicked and a blank canvas opens instead of a note.
- Covers: 4fde906

## 3 · Collab: shared properties

- Description: Two people can edit a shared note's properties at the same time.
- Shows: Two cursors edit different properties on a shared note at once. Both changes stay after syncing.
- Covers: e8c0f8e

## 4 · Agent issue reports

- Description: An agent can report a Kanso problem, and you approve it first.
- Shows: An agent drafts a problem report. A review sheet shows the full text and the user taps Approve before it is sent.
- Covers: 11712fe

## 5 · Schedule view

- Description: See tasks by month or week, and drag them to new days.
- Shows: A month calendar switches to week view. A task is ticked off, then dragged to another day.
- Covers: afcf1d4

## 6 · Share a whole notebook

- Description: Share a notebook with roles, invitations and edit history.
- Shows: The share dialog invites someone as an editor. The notebook then shows who edited each note.
- Covers: 7120f31

## 7 · iPhone App Intents

- Description: Capture, add tasks, search and open notes from iPhone shortcuts.
- Shows: An iPhone Shortcuts screen lists Kanso actions for capture, tasks, search and open. One runs and a note appears.
- Covers: f1486d1

## 8 · Search repairs itself

- Description: A damaged search index rebuilds itself, and failures say why.
- Shows: A search runs while a banner says the index is rebuilding. A failed search shows a clear reason.
- Covers: 1fe5ce6

## 9 · Better MCP answers

- Description: MCP tools answer properly, and kanso --version prints the version.
- Shows: A terminal runs kanso --version and prints the version. An MCP tool call returns a clean result.
- Covers: e0a3d24
